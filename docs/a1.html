Assignment 1: Blink!

"You work for a holiday light company and the chief innovation officer wants you to come up with a cool new pattern of blinking lights.

You will create a schematic for at least 3 LEDs connected to your Arduino, which you will implement as a circuit on your breadboard. You will write firmware (in a .ino file) for the circuit that makes the LEDs blink in a pattern. You will also answer some questions."


Planning

I started this assignment off by writing out the requirements of the assignment:

  • Use 3+ LEDs (any colors)
  • Limit current flowing using resistors
  • Each LED should blink (independently)
  • Comment each line of code

Since the assignment was holiday-themed, I thought I could blink colorful lights to a holiday tune. I chose "Jingle Bells" because it is classic, and it doesn't have too much rhythmic or melodic complexity. Since it only has four notes, I only needed four LEDs.


Schematic

I drew a schematic to visualize my 4-LED circuit.


Calculations

I found the LED forward voltages and suggested using current for each color in datasheets online. I then did some math to figure out which resistors to use so I wouldn't explode my LEDs. Each LED required a resistor between 100Ω and 150Ω. The closest resistors in my kit were 100Ω and 220Ω, so I went with 220Ω for all of them to be safe.


Construction

I brought my drawings to life by building my circuit using my breadboard, Arduino, wires, LEDs, and 220Ω resistors.

Additional questions

1: Draw a graph where the X axis is time and the Y axis is voltage across the LEDs. Draw a line for each of your 3 LEDs.
2: How many LEDs could you blink independently with your Arduino? How much current would that draw?
If you are blinking the LEDs independently (i.e., they're not on simultaneously), we can treat the system like a simple series circuit. Each LED has a suggested current usage of ~20mA (~0.02 A). Kirchoff's Current Law states that the current through a simple series loop (which we have here) is constant. Therefore, the current drawn would be ~0.02A-- and this would be the case for each LED when switched on. As such, you could have as many LEDs as you want, really! The current would stay between 0 and ~0.02A, which wouldn't cause problems.

3: How fast do you need to blink your LEDs until you no longer can tell that they are blinking?
I built a simple single, red LED circuit and used built-in Blink to experiment with various times. I could see blinking with 14ms on, 14 ms off. I could not see blinking with 13ms on, 13ms off.
