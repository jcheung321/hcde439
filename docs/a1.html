Assignment 1: Blink!

"You work for a holiday light company and the chief innovation officer wants you to come up with a cool new pattern of blinking lights.

You will create a schematic for at least 3 LEDs connected to your Arduino, which you will implement as a circuit on your breadboard. You will write firmware (in a .ino file) for the circuit that makes the LEDs blink in a pattern. You will also answer some questions."


Planning

I started this assignment off by writing out the requirements of the assignment:

  • Use 3+ LEDs (any colors)
  • Limit current flowing using resistors
  • Each LED should blink (independently)
  • Comment each line of code

Since the assignment was holiday-themed, I thought I could blink colorful lights to a holiday tune. "Jingle Bells" seemed like a solid classic with not too much rhythmic complexity and only four notes.


Schematic

I drew a schematic to visualize my 4-LED circuit.


Calculations

I found the LED forward voltages for each color and suggested current in datasheets online. I then did some math to figure out which resistors to use so I wouldn't explode my LEDs. Each LED required a resistor between 100Ω and 150Ω. The closest resistors in my kit were 100Ω and 220Ω, so I went with 220Ω for all of them to be safe.


Construction

I then brought my drawings to life by building my circuit using my breadboard, Arduino, wires, LEDs, and 220Ω resistors.


Code

I then wrote some code to blink the lights to "Jingle Bells." 

        
          // the setup function runs once when you press reset or power the board
          void setup() {
            // initialize digital pin LED_BUILTIN as an output.
            pinMode(12, OUTPUT); // Using pin 12 as an output (BLUE)
            pinMode(8, OUTPUT); // Using pin 8 as an output (GREEN)
            pinMode(7, OUTPUT); // Using pin 7 as an output (YELLOW)
            pinMode(4, OUTPUT); // Using pin 4 as an output (RED)
          }
  
          // the loop function runs over and over again forever
          void loop() {
            // Everything off
            digitalWrite(12, LOW); // Blue LED off
            digitalWrite(8, LOW); // Green LED off
            digitalWrite(7, LOW); // Yellow LED off
            digitalWrite(4, LOW); // Red LED off
